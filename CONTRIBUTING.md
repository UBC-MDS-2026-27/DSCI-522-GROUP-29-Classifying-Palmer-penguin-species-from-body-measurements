# Contributing

This is a student project for a class, but if you wish to contribute, please reach out to the repo admins.

## Prerequisites

Before you make a pull request, you should always file an issue and make sure someone from the team agrees that it's a problem. If you've found a bug or wish to recommend a feature, create an associated issue.

For features, at a minimum, describe the feature, its benefit, and how it differs from what is currently offered.

For bugs, at a minimum, describe the current behavior, its detriment, and how it would ideally behave.

## Pull request process

*  Create a branch and tie it to the issue it addresses
*  You will receive feedback and code reviews as we are able

## Code of Conduct

Please note that this project is released with a [Code of Conduct](CODE_OF_CONDUCT.md). By participating in this project you agree to abide by its terms.

## AI Policy

You are responsible for any code you submit to this repo, regardless of whether it was manually written or generated by AI. You must understand and be able to explain both the code you submit and the existing related code; submitting a patch you cannot explain yourself is not acceptable. The explanation must be yours, though you may use AI to translate or copy-edit it.

The use of an AI agent that writes code and then submits a pull request autonomously is not permitted. A human must check any generated code and open the pull request themselves.
